Ace Uploader — UI Design Concepts

Two phone-first layouts for the single-page upload surface (AD-1). Both use Nuxt UI 4 component patterns and portfolio-style tokens. Open this file in a browser — fully offline, no JS.

Nuxt UI 4 v1 scope Phone-first No auth

Design A — Minimal Queue Recommended v1

Closest to current pages/index.vue. Portfolio blue primary, smallest diff.

Who it's for: Kevin uploading from his phone after a nap photo session — wants zero friction, no decoration.
Nuxt UI mapping: UContainer · UButton (block, loading) · native input[type=file] · UAlert (success/error, subtle)
Spine fit: AD-1, AD-4, FR15. No queue list — deferred to v1.1 per memlog.
